# ReWatch(Iot) in operation

ReWatch(Iot) is an open-source project built around three local roles. Sentinel observes an authorized network and records events; Core combines observations and device conditions into a risk state; Herald sends incident notifications. A browser gives the operator current readings, event history and supported per-device controls. The enclosure's ESP32-C3 displays engine state, while the optional WROOM board provides a four-room Black Hat AC model. Follow the [installation guide](install.md) to reproduce the setup with the appropriate hardware.

When a condition reaches RED, Core opens an incident and starts the configured acknowledgement window—120 seconds by default in the live stack. Acknowledgement assigns operator ownership and cancels automatic escalation; it does not repair the device or establish its trustworthiness. Without acknowledgement, the configured response can request a safe setpoint or another supported action. A request is not proof of physical actuation, SMTP acceptance is not inbox delivery, and local firewall rules do not isolate LAN peers unless the host is in their traffic path.

Black Hat provides a separate exercise workspace with 28 generated office assets, four per kind, and a 20-second acknowledgement default. AC spikes, varied alerts, replay and recovery illustrate the same operating workflow without claiming real attacks or physical discovery. The WROOM AC rig likewise models temperatures in software rather than controlling mains equipment. [Deployment acceptance](hardware.md#deployment-acceptance) and the [security model](SECURITY.md) explain what each installation must verify. Neither Black Hat exercises nor successful compilation substitute for those checks.
